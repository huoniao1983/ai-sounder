# 界面功能现状与验收

以下记录本轮可演示能力与仍受外部条件限制的部分。

| 页面/能力 | 当前状态 | 可用动作 | 边界 |
| --- | --- | --- | --- |
| 直播台 | 可用 | 首页展示多个直播专场；两步创建并配置平台、音色、BGM、播放模式和文案；进入专场后一键开播 | 真实平台事件依赖官方授权参数 |
| 文案 | 可用 | 编辑与权重，Base URL/模型/API Key 弹窗配置，AI 生成写入文案组，数据保存在本地 | 需本地 API 服务在线并配置有效大模型 |
| 互动 | 可用 | 进入/礼物/关注/关键词/点赞规则启停、模板、模式、关键词，模板试听 TTS，配置本地保存 | 真平台事件触发需要平台接入 |
| 背景音乐 | 可用 | 2 首真实 MP3 顺序播放、上一首/下一首、播放当前曲目和音量调节 | 授权证明仍需由用户补充 |
| 音色 | 可用 | 千问 CosyVoice v3.5 Flash 在线合成；通过公网样本 URL 创建、命名和描述克隆音色 | 需要千问 API Key 和公网音频 URL |
| 线索 | 演示级 | 展示打分分级，可导出 CSV | 暂无真实弹幕写入与 Webhook |
| 设置 | 可用 | 抖音/快手 WebSocket 地址、Headers、Params 配置和连接管理；Ducking 与音频参数本地保存 | 官方二进制 Protobuf 网关需前置解码桥 |
| 桌面打包 | 脚手架完成 | Tauri 自动启动 Python 能力进程；Sidecar 构建脚本与资源/数据目录约定就绪 | 执行 `desktop/scripts/build-sidecar.ps1` 后即可开启 NSIS 打包 |
| 平台事件 | 可用 | 统一事件模型、抖音/快手适配器、回调转发、状态查询和事件缓存 | 需从官方开放平台取得授权参数 |

启动方式：

```powershell
python -m engine.api_server --host 127.0.0.1 --port 8765
cd desktop
npm run dev
```

访问 http://localhost:1420/。页面中的播放、试听和合成均通过本地能力服务读取真实文件或调用真实 TTS。
